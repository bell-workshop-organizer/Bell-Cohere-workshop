# Bell–Cohere All IN Workshop Montreal 2026

Materials for the Bell–Cohere hands-on workshop on Cohere North.

Participants will:
1. Build and test an RFP proposal agent.
2. Add it to an RFP automation workflow.
3. Test the workflow using the supplied sample RFPs.

Start with **Handout.pdf**. The remaining files contain sample documents and importable North automations.
